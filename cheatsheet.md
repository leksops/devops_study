# Моя DevOps шпаргалка

## Навигация в Linux / PowerShell:
* `pwd` — показывает, в какой папке я сейчас нахожусь.
* `mkdir` — создает новую папку.
* `ls` — показывает список файлов в текущей папке.
* `cd имя_папки` — зайти внутрь папки.
* `cd ..` — выйти назад на один уровень вверх.
* `New-Item имя_файла` — создать новый пустой файл.
* `cat имя_файла` — прочитать и вывести содержимое файла на экран.
* `rm имя_файла` — удалить файл навсегда (без Корзины!).
  `rm имя_папки -Recurse` — принудительно удалить папку и всё, что внутри неё, без лишних вопросов. *(В настоящем Linux вместо -Recurse пишется флаг -rf, например: rm -rf имя_папки).*
* `Set-Content имя_файла` - написать текст внутри файла 
## Урок 2. Архитектура и структуры
* `mkdir папка1, папка2` — создание нескольких папок сразу.
* `ls имя_папки` — посмотреть, что лежит внутри конкретной папки.
* Контуры серверов: Dev (разработка), Stage (тесты), Prod (боевой сайт).
* `mv старое_имя новое_имя` — переименовать файл.
* `mv файл папка/` — переместить файл в другую папку.
* `cp файл папка/` — скопировать файл в другую папку.
## Переменные окружения (Environment Variables)
* Переменные окружения — это «бумажки с инструкциями» в памяти компьютера, которые подсказывают программам, где они запущены (например, на тестовом сервере или боевом).
* `$env:STAGE="production"` — создать переменную с именем STAGE и значением production (в Windows).
* `echo $env:STAGE` — вывести значение переменной на экран.
* `Remove-Item Env:\STAGE` — удалить переменную из памяти.

>>>## Команды Linux Bash (Реальный DevOps-стандарт)
* `pwd` — показать текущий путь.
* `ls` — показать файлы в папке.
* `mkdir имя_папки` — создать папку.
* `mkdir -p папка1/папка2` — создать папку сразу со вложенной папкой (замена пути через слэш).
* `touch имя_файл.txt` — СОЗДАТЬ ПУСТОЙ ФАЙЛ (замена New-Item).
* `echo "текст" > файл.txt` — записать текст в файл (замена Set-Content).
* `cat файл.txt` — прочитать файл.
* `mv старое новое` — переместить или переименовать.
* `cp старое новое` — скопировать.
* `rm файл.txt` — удалить файл.
* `rm -rf имя_папки` — ПРИНУДИТЕЛЬНО удалить папку и всё внутри без вопросов (замена -Recurse).
* `export STAGE="production"` — СОЗДАТЬ ПЕРЕМЕННУЮ ОКРУЖЕНИЯ (в Linux вместо $env:).
* `echo $STAGE` — вывести переменную (в Linux знак $ пишется перед именем).
## Права доступа в Linux
* `ls -l имя_файла` — посмотреть подробные права доступа.
* `chmod три_цифры файл` — изменить права доступа (4=read, 2=write, 1=execute).
* `chmod 755 script.sh` — разрешить запуск скрипта (стандарт).
* `chmod 600 config.env` — скрыть файл с паролями от всех, кроме владельца.
## Урок 3. Основы Git
* `git init` — включить слежку Git для текущей папки (создать репозиторий).
* `git status` — проверить состояние файлов (что изменилось, что не сохранено).
* `git add .` — подготовить все измененные файлы к сохранению.
* `git commit -m "сообщение"` — сделать снимок (сохранить изменения в историю).
* `git log` — посмотреть историю всех сделанных снимков (коммитов).
* `/mnt/c/` — так в Linux обозначается Диск C вашей Windows.
* `git checkout .`
* `git branch имя_ветки` — создать новую ветку для задач.
* `git checkout имя_ветки` — переключиться на указанную ветку.
* `git branch -d имя_ветки` — удалить ветку навсегда.
* `git checkout -b имя_ветки` — создать ветку и сразу перейти в неё.
* `git merge имя_ветки` — влить изменения из указанной ветки в текущую.
* `git push -u origin main` — отправить сохраненные коммиты на GitHub.
